# SYSTEM

## File structure

```bash
System/
├── README.md
├── DataSetRandomizer.py
```

This is just for conducting the experiment, by splitting up the audio files to separate directories.

- **Evaluation**: Folder containing audio files.
- **Training**: Folder containing audio files.
